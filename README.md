# 🏋️ AI Gym Trainer

An AI-powered fitness coaching application that helps users perform workouts with proper posture using real-time pose detection. The application analyzes body movements through a webcam, counts repetitions, provides posture feedback, and helps users improve exercise accuracy.

## 🚀 Features

* 🎥 Real-time pose detection using a webcam
* 🤖 AI-based exercise posture analysis
* 🔢 Automatic repetition counting
* 📊 Live workout feedback
* 💪 Supports multiple exercises
* 🖥️ Simple and interactive user interface

## 🛠️ Tech Stack

* Python
* OpenCV
* MediaPipe
* NumPy
* Tkinter / Streamlit (depending on your project)
* Machine Learning
* Computer Vision

## ⚙️ Installation

### 1. Clone the repository
git clone https://github.com/anjalipacharne013-debug/AI-Gym-Trainer.git

### 2. Navigate to the project
cd AI-Gym-Trainer

### 3. Create a virtual environment
python -m venv venv

### 4. Activate the virtual environment

Windows:
venv\Scripts\activate

Linux/macOS:
source venv/bin/activate

### 5. Install dependencies
pip install -r requirements.txt

### 6. Run the application
python main.py
